# Feature 003: レイアウト再構成(サイドバー + キャンバス + パネル)

Phase: [Phase 2](../../docs/plan/phase-2-usability.md)

## Goal

実機調査で発見した構造的バグ(ノートが増えるとグラフキャンバスのノードが
ノート編集フォームに重なって表示される)を根本解決し、主要な操作を継続して
行える画面構成にする。

## Scope

- ページ全体をビューポート高に収まるレイアウトに変更する: 左に固定幅の
  サイドバー(ノート一覧、縦スクロール可)、中央にグラフキャンバス(残り幅・
  残り高さいっぱいに拡張)、選択中ノートがある時のみ右側に固定幅の編集
  パネルを表示する(現状の条件表示は維持)
- グラフキャンバスの `overflow` を正しく処理し、ノードが他要素にはみ出さない
  ようにする
- `NoteGraph` の高さを固定値(400px)ではなく親要素いっぱい(`height: 100%`)に変更
- ノート追加時にキャンバスが新しいノードも見える範囲になるよう、ノート数が
  変わるたびに再フィットする
- 選択中のノート(一覧の項目・グラフのノード)を視覚的に区別する最小限の
  スタイル(背景色や枠線)を付与する
- 空状態(ノート0件)のキャンバスに一行だけ案内文を表示する

## Out of Scope

- モバイル/狭幅レスポンシブ対応
- パネルのリサイズ・折りたたみ・ドラッグでの幅変更
- 装飾目的のデザイン(配色・アイコン等)

## Acceptance Criteria

- ノートを8件程度作成しても、グラフノードがエディタパネルや一覧に重ならない
- 選択中のノートが一覧・グラフの両方で見た目上わかる
- ノートが0件の状態で、何をすればよいか画面内の文言だけで分かる

## Verification

- `tests/e2e/notes.spec.ts` の接続シナリオに、複数ノート作成後の重なり無し
  確認を追加する
- `pnpm run verify` および `pnpm run test:e2e` が通ること
