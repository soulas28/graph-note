# Feature 005: ノート削除のUndo(元に戻す)

Phase: [Phase 2](../../docs/plan/phase-2-usability.md)

## Goal

ノート削除の誤操作によるデータ消失リスクを、確認ダイアログではなく
取り消し操作で緩和する。

## Scope

- ノート削除時、削除された `Note` と、カスケード削除された `Edge[]` を
  直近1件分だけ一時的に保持する(単一スロット。新たな削除で上書きされる)
- 削除直後に軽量な通知(「ノートを削除しました」+「元に戻す」ボタン)を表示し、
  クリックすると削除前の状態(ノート・関連Edgeとも)を復元する
- 復元は状態管理層(`page.tsx`)で直接ノート・Edgeを配列に戻す形で行う

## Out of Scope

- 複数手のUndo/Redoスタック
- 作成・編集・リンク操作のUndo(削除のみが対象)
- Undo情報の永続化

## Domain Rules

- `notes.ts`/`edges.ts` に新しいドメイン関数は追加しない(既存の配列操作で
  復元を表現する)
- Undo情報はメモリ上のみ、単一スロットのみ保持する。**汎用的な操作履歴
  (Undo/Redoスタック、他操作への拡張)を見据えた設計は行わない** —
  将来汎用履歴が必要になった時点で、その時の要件に応じて改めて設計する

## Acceptance Criteria

- ノートを削除した直後に「元に戻す」を押すと、削除前の状態(ノート・
  接続していたEdgeとも)に戻る

## Verification

- `tests/e2e/` に削除→Undo通知の表示→クリックで復元、の一連をテスト化する
- `pnpm run verify` および `pnpm run test:e2e` が通ること
